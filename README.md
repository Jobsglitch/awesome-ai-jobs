## How this list is built

- Jobs come straight from employers' own hiring systems (Greenhouse, Lever, Ashby, Workday and others), collected by [JobsGlitch](https://jobsglitch.com).
- A role is listed only when the employer states the pay. Nothing here is estimated.
- A role is listed only if it was still open on the employer's page at the last check. Closed roles drop off at the next daily rebuild.
- Each company gets at most four rows, newest first, so one large employer cannot fill the list.
- "Apply" goes to the employer's own page. "Check my fit" opens the same job on JobsGlitch.
- Locations are read automatically and can be wrong; the employer's page is the authority.
- The same rows are in [`jobs.json`](jobs.json) for anyone who wants the data.
- Found a mistake? Open an issue.
